About QuickNotes

QuickNotes is a simple web application that allows you to quickly capture and organize your ideas and notes.

How to use QuickNotes

  1. Add new notes
  2. View your notes
  3. Edit and delete notes

Features

  • Add new notes
  • View your notes
  • Edit and delete notes
Keyboard shortcuts
Shortcut Action Comment
Ctrl + S Save the note. Save the comment.
Ctrl + D Delete the note. Delete the comment.
